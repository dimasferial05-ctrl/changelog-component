# Changelog Component

Proyek ini adalah solusi untuk tantangan "Changelog Component" dari [roadmap.sh]([https://roadmap.sh/](https://roadmap.sh/projects/changelog-component)). Fokus utama dari proyek ini adalah mengasah kemampuan dalam pengaturan tata letak (*layouting*) dan pemosisian elemen menggunakan CSS (*CSS Positioning*).

Komponen ini mencatat perubahan atau pembaruan penting dalam sebuah proyek perangkat lunak, disajikan dalam bentuk *timeline* yang bersih dan informatif.

## ✨ Fitur Utama

- **CSS Positioning:** Menggunakan kombinasi `position: relative` dan `position: absolute` untuk menciptakan garis *timeline* vertikal dan titik penanda (dots) yang presisi di tengah.
- **Responsive Layout:** Menggunakan Flexbox untuk membagi area tanggal (kiri) dan konten (kanan). Tampilan otomatis berubah menjadi satu kolom yang rata kiri saat dibuka di perangkat *mobile* (responsif).
- **Clean UI:** Desain minimalis yang terinspirasi dari standar industri, menggunakan font Inter untuk keterbacaan yang lebih baik.
- **HTML Semantik:** Menggunakan tag `<article>`, `<section>`, dan `<header>` untuk struktur dokumen yang bermakna.

## 📂 Struktur Proyek

- `index.html` - Berisi struktur HTML untuk komponen changelog.
- `style.css` - Berisi logika desain, sistem pemosisian, dan aturan responsif.

## 🛠️ Teknologi yang Digunakan

- **HTML5**
- **CSS3** (Flexbox, Absolute/Relative Positioning, Media Queries)
- **Google Fonts** (Inter)
